# Compatibilidad

- Probado en Chromium (Playwright, escritorio 1280 px y móvil 390 px).
- El mapa requiere WebGL (MapLibre GL). Sin WebGL se muestra un mensaje en lugar del mapa.
- Las notificaciones del navegador requieren permiso y la API Notification. El sonido requiere una interacción previa (al activar el interruptor).
- Los selectores de fecha nativos muestran el formato de la configuración regional del navegador.
